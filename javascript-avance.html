03 · Interaction

JavaScript utile

JavaScript relie les actions de la personne à l’état de la page. En séparant les données, les événements et l’affichage, ton code devient plus facile à suivre.

01 / ÉVÉNEMENTS

Réagis à une action sans mêler les couches

Place la structure du bouton dans le HTML, puis écoute son événement dans le script. Ici, le compteur évolue dans une variable et seul le texte affiché est mis à jour.

const button = document.querySelector("#add");
const output = document.querySelector("#count");
let count = 0;

button.addEventListener("click", () => {
  count += 1;
  output.textContent = String(count);
});
02 / DONNÉES

Transforme une liste avant de l’afficher

filter choisit les éléments qui correspondent à un critère. map transforme chaque élément conservé. Ces méthodes créent de nouvelles listes au lieu de modifier la liste d’origine.

const lessons = [
  { title: "HTML", minutes: 12 },
  { title: "CSS", minutes: 18 },
  { title: "JavaScript", minutes: 25 },
];

const shortLessons = lessons
  .filter((lesson) => lesson.minutes <= 20)
  .map((lesson) => lesson.title);

console.log(shortLessons);
03 / ASYNCHRONE

Prévois les erreurs d’une requête

Une requête réseau peut échouer, même si le code est correct. Avec async et await, le déroulement reste lisible; try/catch permet de traiter l’erreur au même endroit.

async function loadLessons() {
  try {
    const response = await fetch("/api/lessons");
    if (!response.ok) throw new Error("Réponse invalide");

    const lessons = await response.json();
    return lessons;
  } catch (error) {
    console.error("Chargement impossible", error);
    return [];
  }
}
