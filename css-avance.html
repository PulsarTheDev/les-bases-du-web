02 · Présentation

Du CSS qui tient la route

Le CSS ne sert pas qu’à choisir des couleurs. Il aide à organiser les éléments, à gérer différentes tailles d’écran et à rendre les interactions visibles.

01 / COHÉRENCE

Centralise les valeurs qui reviennent

Les propriétés personnalisées permettent de réutiliser les mêmes couleurs ou espacements. Un changement dans un seul endroit met à jour toutes les règles qui utilisent la variable.

:root {
  --ink: #f4eeee;
  --surface: #151012;
  --accent: #e52b45;
  --space: 1.25rem;
}

.notice {
  padding: var(--space);
  color: var(--ink);
  border-left: 3px solid var(--accent);
}
02 / MISE EN PAGE

Laisse Grid répartir le contenu

Avec minmax() et auto-fit, une grille crée autant de colonnes que possible, sans imposer une largeur fixe aux petits écrans. Les éléments passent naturellement à la ligne.

.gallery {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

.gallery img {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
}
03 / INTERACTION

Rends le focus et le mouvement prévisibles

Une indication de focus visible aide à suivre la navigation au clavier. Les préférences de mouvement réduit permettent de désactiver les transitions non essentielles pour les personnes qui le demandent.

a:focus-visible,
button:focus-visible {
  outline: 3px solid var(--accent);
  outline-offset: 3px;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto !important;
    animation-duration: .01ms !important;
  }
}
