Un site, trois rôles

Ces langages travaillent ensemble, mais chacun répond à une question différente.

01 / CONTENU

HTML structure

Il donne un sens au contenu : titres, paragraphes, liens, images et formulaires.

<h1>Mon jardin</h1>
02 / APPARENCE

CSS présente

Il règle la mise en page, les couleurs et l’adaptation aux différentes tailles d’écran.

h1 { color: forestgreen; }
03 / ACTION

JavaScript réagit

Il répond aux actions, met à jour la page et peut échanger des données avec un serveur.

button.addEventListener(...)

Un bon réflexe : commence par un HTML compréhensible, ajoute le CSS, puis le JavaScript nécessaire aux interactions.
